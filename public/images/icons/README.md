# Iconos para Core Characteristics

Esta carpeta contiene los iconos para la sección "Core characteristics of the FiTI".

## Iconos necesarios (6 total):

1. **fisheries-management.png** - Icono de objetivo/target para "Fisheries Management"
2. **collective-action.png** - Icono de manos colaborativas para "Collective Action"  
3. **visibility-usability.png** - Icono de monitor/computadora para "Visibility & Usability"
4. **progressive-improvement.png** - Icono de engranajes para "Progressive Improvement"
5. **quality-source.png** - Icono de gráfico ascendente para "Quality At Source"
6. **robust-assurance.png** - Icono de lupa con análisis para "Robust Assurance"

## Formato recomendado:
- **Formato**: PNG con fondo transparente
- **Tamaño**: 64x64px o 128x128px 
- **Color**: Azul FiTI (#1e4a66) o compatible con el branding

## Uso:
Los iconos se referencian desde el código como:
`/fiti-clon/images/icons/nombre-del-icono.png`
