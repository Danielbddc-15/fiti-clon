# FiTI — Homepage Clone (React + Vite)

Proyecto inicial para clonar visualmente la página de inicio de https://fiti.global/ usando React y Vite.

Qué contiene:
- Scaffold mínimo Vite + React
- Componentes: Header, Hero, Features, Numbers, News, Footer
- Estilos básicos en `src/styles.css`

Cómo usar:

1. Abrir PowerShell en la carpeta del proyecto:

```powershell
cd c:\Users\admin\Desktop\FITIrjs
```

2. Instalar dependencias:

```powershell
npm install
```

3. Levantar servidor de desarrollo:

```powershell
npm run dev
```

Notas:
- Este es un clon visual inicial. No se han incorporado imágenes ni fuentes propietarias del sitio original.
- Si quieres que baje automáticamente imágenes, logos y estilos exactos, dime y procedo (toma en cuenta licencias y derechos de autor).
- Puedo continuar ajustando estilos para que coincida pixel-perfect, añadir responsividad y exportar assets.
