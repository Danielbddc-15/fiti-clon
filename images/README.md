# Imágenes de FITI Global

Esta carpeta contiene las imágenes utilizadas en el proyecto FITI Global.

## Estructura de carpetas:

- `/news/` - Imágenes para la sección de noticias
- `/countries/` - Imágenes adicionales de países (opcional)
- `/events/` - Imágenes de eventos y reuniones (opcional)

## Imágenes necesarias para la sección de noticias:

1. **students-meeting.jpg** - Reunión virtual de estudiantes internacionales
2. **compliance-system.jpg** - Diagrama del sistema de compliance de FiTI
3. **wto-forum.jpg** - Foro público de la OMC sobre subsidios pesqueros
4. **caribbean-dialogue.jpg** - Reunión del diálogo regional del Caribe
5. **cabo-verde-coast.jpg** - Costa de Cabo Verde / Puerto pesquero
6. **ghana-inauguration.jpg** - Ceremonia de inauguración del MSG en Ghana
7. **indonesia-assessment.jpg** - Informe TAKING STOCK de Indonesia

## Instrucciones:

1. Guarda las imágenes reales de FITI en esta carpeta con los nombres indicados
2. Las imágenes deben tener una resolución de al menos 800x480px
3. Formatos recomendados: JPG, PNG o WebP
4. Optimiza las imágenes para web (compresión adecuada)

Una vez que tengas las imágenes, actualiza las rutas en `src/App.jsx`.
